# 💼 Salary Prediction using Machine Learning

## 📌 Project Overview

Salary Prediction is a Machine Learning project that predicts an employee's salary based on factors such as experience, education level, job role, age, and working hours. This project helps organizations estimate salaries and assists job seekers in understanding expected compensation.

The model is trained on historical employee data and deployed using Streamlit for real-time salary prediction.
